# 残響都市

人間と、あとから入った AI の両方が読める説明。

## このアプリがやること（だけ）

1. シードから、同じ滅び方を毎回返す（決定論）
2. 文明名は 修飾×領域×機関（各 14 語、約 2,744 通り）
3. 核は 部位×状態×形、断片の題は 対象×媒体×残り方（同じく 14×14×14）
4. iPhone のタッチで歩き、視線を動かし、灯火と測量閃を使う
5. 入口の輪に触れて出た断片だけを、連携 ID の記録に残す
6. 触れずに出たら緊急脱出。その探索の断片は没収し、脱出ログだけ残す
7. 脱出のたび、入口のシードを引き直す

やらないこと: 物理エンジン、マルチプレイ、連携なしの配信許可。

## ファイル分担

- `src/game/words.ts` … 語彙と名前の組み立て。地形は持たない
- `src/game/gen.ts` … 部屋・廊・崩壊・スポーン。語の中身は words.ts
- `src/game/echoes.ts` … Three.js の歩行・霧・衝突・閃光。HUD は持たない
- `src/game/ghosts.ts` … おばけの形。ギャラリーと本番で同じ
- `src/game/hitodama.ts` … 人魂の炎。罰なし。色はゲーミング


- `src/game/input.ts` … キー・スティック・ゲームパッドのサンプリングだけ
- `src/game/audio.ts` … 足音・拾得・閃光。見た目は持たない
- `src/game/rng.ts` … シード乱数
- `src/components/echoes-app.tsx` … 入口・HUD・離脱。WebGL は engine に委譲
- `src/lib/finds.ts` … 拾得の commit と緊急脱出ログ
- `src/lib/profile.ts` … プロフ名。OAuth の name を上書きしないための別表
- `src/lib/admin.ts` … 管理者。ビルトインは touko5536@gmail.com。付与は ID のみ
- `src/lib/settings.ts` … 部屋・灯火の明るさと霧の距離。全員共通。書くのは管理者だけ




- `src/routes/profile.tsx` … 名と ID。入口のチップでは書かない

- `src/routes/terms.tsx` … 配信規約（ビデオポリシー）
- `migrations/` … 適用済みは編集しない

## コーディング方針（何も知らない AI 向け）

このリポジトリは、別セッションの AI が途中から読んでも迷わないことを優先する。
コードを読む相手は「昨日の会話を覚えていない AI」だと仮定する。

### コメントに書くこと

- **何をしているかより、なぜそうしているか** を書く。
- 関数・ファイルの先頭で、役割・やらないこと・前提・失敗して捨てた案を短く書く。
- 一見不思議な行には、制約か事故の理由を残す。
- 名前で分かる処理にはコメントを付けない。
- コメントは日本語。人間と AI の両方の第一言語を日本語に揃える。

### コメントに書かないこと

- コードを言い換えただけの説明
- 将来やるかもしれない機能の予告
- 捨てた案の長話。一行の理由で足りる

### 変更するとき

- 意図が変わったら、先にコメントを直してからコードを直す。
- コメントとコードが食い違っているなら、コメントが古い。コードに合わせてコメントを直す。
- 新しい制約を踏んだら、その場に一行で理由を残す。Issue やチャットにしか書かないと、次の AI は見えない。
